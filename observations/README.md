# Observed Transition Examples

This directory contains short observational companions to **The Collapse of the Semantic Middle**.

These notes do not claim that broad linguistic collapse is inevitable, nor that any single example proves the paper's full hypothesis. Each note documents one or more already-visible components of the proposed mechanism:

- expressive offloading;
- interpretive offloading;
- shrinking human audit layers;
- ritualised rather than substantive human participation;
- path-of-least-resistance behaviour;
- machine occupation of the semantic middle.

## Evidence labels

- **Firsthand observation** — directly experienced and documented by the project author.
- **Present capability** — technically available in ordinary consumer systems now.
- **Near-term extrapolation** — requires only one or two clearly identified changes to the observed workflow.
- **Long-range scenario** — speculative downstream consequence and not treated as present fact.
